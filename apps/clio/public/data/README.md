# Word data

Generated and committed. Rebuild with the scripts in `../../scripts/`.

- `hsk.json`: HSK 3.0 (2021) word list, from
  [complete-hsk-vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary)
  (MIT), which takes its words from [hsk30](https://github.com/elkmovie/hsk30)
  (MIT, (c) 2021 Pleco Inc.). `build-hsk.mjs`.
- `dictionary.json`: [CC-CEDICT](https://cc-cedict.org), (c) MDBG, CC BY-SA 4.0.
  Trimmed and with pinyin in tone marks. `build-dictionary.mjs`.

See the root `NOTICE`.
